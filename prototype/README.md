# Prototype (frozen reference)

This folder holds the original **vanilla-JS prototype** of the SEO Autopilot dashboard —
a hash-routed single-page app backed by `localStorage`, with the SiteGuru integration
faked (mock data in `data.js`, "Pull SiteGuru" wired to toasts only).

It is kept **only as a design/UX reference** for the real Next.js + Supabase build that
now lives at the repo root. Do not develop against it. Design tokens, screen layouts, and
copy were ported from here — see `styles.css` for the canonical design tokens.

To view it, open `index.html` directly in a browser.
